# Papoiongo

Idioma en clave (Mick + Connor)."papoi". esta basado en referencias a los MINIONS.

## Reglas

- se utilizan idealmente una palabra sin particula "poi". seguida de otra que si la tiene. alternando entre ellas no estrictamente.
- definiciones: <termino_corto> = termino sin particula "poi". ej: "ñapoi" ==> "ña"
    <termino_combinado> = <termino_corto>termino. Ej: "pipoi ñamapoi" ==> "piñamapoi"
- oracion tipica formato : "<termino_corto> termino <termino_combinado>"
- al no ser estricto, se pueden agrupar terminos , por ej: "ñakachepoi cajopoi papoi" ==> "ñakachecajopoi papoi" (es preferible usar "papoi" completo solo cuando se usa la oracion dirigida a alguien, para que no haya dudas.)
- notas: por lo gral, se omite el yo, se agrega en cualquier lado cuando el pronombre es dudoso. aunque cuando se dirije a alguien, se agrega el "papoi" al final para dejar claro a quien se dirije la oracion
- se puede agregar "papoi" al final de cada oracion, sin que signifique necesariamenete "vos", se interpretaria como "dirigido a vos"
- Pocas palabras, sin conjugaciones ni tiempos verbales: el verbo se usa tal cual para todo, el contexto hace el resto.
- Orden: sujeto + verbo o alreves. `shoñamapoi`  = voy a comer. `ñamapoi papoi` = ¡come vos! el "sho" por lo gral se omite. lo mas comun seria, `ñamapoi` = voy a comer. y `ñamapoi papoi` o `ñamapapoi` = ¡come vos!. por tanto, cualquier uso de termino o frase,  se refiere a si mismo si se omite pronombre, cuando se refiere a la otra persona, se agrega "papoi" al final para denotar que el sujeto es la otra persona, ya sea la palabra aislada o como parte de la frase dicha o termino combinado.
- Las palabras pueden usarse completas (solas) o abreviadas en frase  y unidas.
- Formación / creacion de palabras: sílabas de 2 letras, 2 o 3 sílabas, terminan en -poi o -i (también pueden empezar con poi- / i-).
- Muchas derivan del español rioplatense; las parecidas entre sí son parte del chiste.
- otros derivados: japones o ingles: ej: gamapoi = jugar (origen "Game")
- `ko-` / `ke-` = intentan ser marcador de pregunta (kotapoi, kotopoi, ketapoi, kodopoi).
- Compuestos: raíces cortas + poi al final. Ej: pi (bien) + vini (venir) + poi = pivinipoi. El poi final es opcional si la raíz ya suena completa. se pueden usar los prefijos solos para dar significado a una frase. ñapoi es "mal", pero ñavedopoi  es "ver mal" (no es necesario usar "ñapoi vedopoi" entero.)
- `poi` / `i` funcionan como partícula final: no tienen significado propio, a veces son obligatorias y a veces opcionales (similar a las partículas finales del japonés).
- Énfasis: alargar las vocales (chiiiipoooiii = ¡chauuu, que te vaya lindooo!).
